# Statable Stats API

Privacy-first, cookieless web analytics from Statable (Key Arg B.V.), EU-hosted in the Netherlands with GDPR compliance and a ~2 KB tracking script. Exposes a server-side REST HTTP API with a public OpenAPI 3.1 contract, a hosted MCP server, an llms.txt, and a CLI for querying visitors, pages, sources, goals, funnels, custom events and live visitors.

## APIs

- **Statable Stats API** — Read-focused REST HTTP API for privacy-first web analytics. Bearer (stbl_) auth, server-side only (no CORS). Endpoints include GET /sites, POST /query, GET /current-visitors, GET /props, GET /funnels, POST /funnels/{id}/report, GET /subscription, plus a flagged key-management write surface. Includes a public OpenAPI 3.1 contract, a hosted MCP server, and an llms.txt. (`https://statable.com/api/v1`)

> Provider exposes a REST API (base https://statable.com/api/v1, dev https://dev.statable.com/api/v1), a public no-auth OpenAPI 3.1 spec, a hosted MCP server (Streamable HTTP, OAuth 2.1) at https://mcp.statable.com/mcp offering 25 tools, and llms.txt files — all confirmed live. No AsyncAPI or GraphQL contract and no published agent skills were found. A local stdio MCP bridge (npx -y @statable/mcp) and a CLI (brew install key-arg/tap/statable) exist but are local surfaces, not cataloged as MCPServer.
